Персональный Telegram-бот на Python (aiogram 3) для оценки и ранжирования промежуточных точек по маршруту с учётом реального дорожного крюка (OSRM), погоды (Open-Meteo) и приоритета точки.

Возможности

Однопользовательский режим по OWNER\_ID.

Расчёт дорожного расстояния и крюка через OSRM Routing API с кэшированием в SQLite и fallback на гаверсинус.

Оценка текущей погоды в точке через Open-Meteo с TTL-кэшем.

Ранжирование точек с вердиктом (Заехать / Под вопросом / Пропустить) и выгрузкой в JSON (/export).
